# 个人主页生成器

一个高度可自定义的个人主页生成器，支持实时编辑、图片上传、弹窗添加内容，以及一键导入导出。

## ✨ 功能特性

### 📝 实时编辑
- **所有文字内容均可点击直接编辑**：姓名、头衔、简介、地点、网站、加入日期等
- 编辑后自动保存到浏览器本地（localStorage），刷新页面不丢失
- 支持编辑社交链接文字、项目名称与描述、友链文字

### 🖼️ 图片上传（自动压缩）
- **头像上传**：点击头像或"上传头像"按钮，自动压缩到 400×400，质量 0.85
- **背景图上传**：点击右上角"更换背景"，自动压缩到 1920×1080，质量 0.75
- 背景图自动添加柔和遮罩层，确保内容清晰可读
- 上传时显示"处理中"提示，避免大图卡顿

### 🔗 链接、项目与友链管理
- **社交链接**：通过弹窗添加，可自定义链接地址、显示文本和 Font Awesome 图标
- **项目**：通过弹窗添加，包含项目名称、链接、描述和图标
- **友链**：通过弹窗添加，包含友链地址、显示文本和图标
- 所有链接项悬浮时右上角显示删除按钮

### 📦 导出与导入
- **导出只读版本**：点击"保存为只读HTML文件"下载独立的 HTML 文件
  - 移除了所有编辑功能、添加按钮、删除按钮
  - 保留展示和链接跳转
  - 适合分享给他人查看，或部署到服务器
- **导入 HTML 文件**：点击"导入HTML文件"按钮，选择之前导出的文件即可恢复内容
  - 支持按钮点击选择文件
  - 支持直接拖拽文件到页面
  - 导入前会弹出确认，防止覆盖当前内容
  - 自动解析姓名、头衔、头像、背景、社交链接、项目、友链等全部内容

## 🚀 快速开始

1. 将代码保存为 `index.html` 文件
2. 用浏览器打开该文件
3. 点击页面上的任意文字即可编辑
4. 所有修改自动保存到浏览器本地

## 🎨 自定义指南

### 修改默认内容
打开 HTML 文件，找到 `<script>` 标签中 `loadProfile` 函数的默认数据部分：

```javascript
data = {
  avatar: 'A',
  name: 'Alex Chen',
  title: '产品设计师 & 开发者',
  bio: '热爱创造简洁优雅的数字产品...',
  location: '上海, 中国',
  website: 'alexchen.design',
  joinDate: '2025年3月',
  // ...
};
```

修改这些默认值即可改变页面初始显示内容。

### 修改页面透明度
找到 CSS 中的 `.profile-card` 样式：

```css
.profile-card {
  /* 数值越小越透明，范围 0-1 */
  background: rgba(255, 255, 255, 0.55);
}
```

同理，可以调整 `.bio`、`.info-row`、`.project-item`、`.friend-link` 等区域的透明度。

### 更换图标
所有图标使用 [Font Awesome 6](https://fontawesome.com/icons) 类名。常用图标对照：

| 平台/用途 | 图标类名 |
|----------|---------|
| GitHub | `fab fa-github` |
| Twitter/X | `fab fa-twitter` |
| LinkedIn | `fab fa-linkedin-in` |
| QQ | `fab fa-qq` |
| 微博 | `fab fa-weibo` |
| 邮箱 | `fas fa-envelope` |
| 博客 | `fas fa-blog` |
| 代码/项目 | `fas fa-code` |
| 链接 | `fas fa-link` |
| 用户/友链 | `fas fa-user` |
| 盒子/项目 | `fas fa-cube` |
| 图表/项目 | `fas fa-chart-line` |

> **注意**：Font Awesome 免费版不包含 Bilibili 图标，如需使用可单独引入 [阿里巴巴矢量图标库](https://www.iconfont.cn/) 的 SVG 图标。

## 📁 文件结构

```
index.html                  # 单文件应用，包含所有 HTML、CSS 和 JavaScript
my-profile-readonly.html    # 导出的只读版本（由工具生成）
```

## 🛠️ 技术栈

- **HTML5**：语义化结构
- **CSS3**：Flexbox 布局、`backdrop-filter` 毛玻璃效果
- **原生 JavaScript**：无框架依赖，轻量高效
- **Canvas API**：图片压缩处理
- **DOMParser**：导入 HTML 解析
- **Font Awesome 6**：图标库
- **Google Fonts (Inter)**：字体

## 💾 数据存储说明

- 所有编辑内容保存在浏览器的 **localStorage** 中
- 存储键名：`custom_profile_page_data_v11`
- **清除浏览器数据会导致内容丢失**，建议定期使用"保存为只读HTML"备份
- 导出的只读文件使用独立的随机存储键，不会覆盖主页面数据

### 图片压缩参数

| 图片类型 | 最大尺寸 | 压缩质量 | 说明 |
|---------|---------|---------|------|
| 头像 | 400 × 400 | 0.85 | 圆形显示够用 |
| 背景图 | 1920 × 1080 | 0.75 | 高清屏足够 |

## 🔒 只读版本说明

导出的 `my-profile-readonly.html` 文件具有以下特点：

- ✅ 保留所有样式、背景图、头像、项目、友链
- ✅ 保留所有链接跳转功能
- ✅ 可以重新导入回主页面，恢复所有内容
- ❌ 移除了所有编辑功能
- ❌ 移除了添加/删除按钮
- ❌ 移除了弹窗、上传控件、导入导出按钮

## 📱 响应式支持

- 桌面端：左右分栏布局（左侧头像，右侧信息）
- 移动端（≤768px）：上下堆叠布局，自动适配

## 🔄 工作流建议

### 备份与恢复
1. 编辑完成后，点击 **"保存为只读HTML文件"** 备份
2. 换电脑或换浏览器时，打开本工具，点击 **"导入HTML文件"** 恢复内容
3. 也可以直接把 `.html` 文件拖拽到页面完成导入

### 分享给他人
1. 点击 **"保存为只读HTML文件"**
2. 将下载的 `my-profile-readonly.html` 发给朋友，或上传到服务器
3. 对方打开后只能查看，无法修改

## 🐛 常见问题

### 保存按钮点击没反应？
确保使用最新版本的代码，早期版本存在函数名大小写错误（`saveAsReadonlyHtml` → `saveAsReadOnlyHtml`）。

### 图标不显示？
检查 Font Awesome CDN 是否正常加载，或确认图标类名是否正确。

### 背景图上传后内容看不清？
调整 `body.has-bg-image::before` 的 `background` 透明度，或调高 `.profile-card` 的背景不透明度。

### 导出的文件太大？
背景图和头像已经过自动压缩，通常不会超过 500KB。如果仍然很大，建议使用更小的原图。

### 导入时提示"不是有效的个人主页文件"？
请确保导入的是本工具导出的 `my-profile-readonly.html` 文件，文件内必须包含 `id="name"` 等关键元素。

### 编辑内容后刷新丢失？
localStorage 可能被禁用（如隐私模式），或浏览器清理了站点数据。
